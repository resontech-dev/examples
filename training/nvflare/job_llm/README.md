# job_llm — General LLM Fine-Tuning (Phi-3.5-mini + LoRA + Alpaca)

Federated instruction-tuning of `microsoft/Phi-3.5-mini-instruct` — the small LLM with the most rigorously documented training on HuggingFace.

## Model

- **Name**: `microsoft/Phi-3.5-mini-instruct`
- **HF link**: https://huggingface.co/microsoft/Phi-3.5-mini-instruct
- **Parameters**: 3.8 B
- **Architecture**: Llama-style decoder transformer
- **Library**: `transformers` + `peft` (LoRA) + `trl` (SFTTrainer)
- **Pretrained**: 3.4 trillion tokens, 10 days on 512×H100-80G GPUs (per Microsoft's card)

## Dataset

- **Name**: `tatsu-lab/alpaca`
- **HF link**: https://huggingface.co/datasets/tatsu-lab/alpaca
- **Format**: `{"instruction": str, "input": str, "output": str}`
- **Examples**: 52,002 instruction-following pairs, generated by GPT-3.5-turbo on Stanford's seed instructions

For different tasks, swap `HF_DATASET` in `build_shards_hf.py`:
- `databricks/databricks-dolly-15k` — 15k human-labeled (cleaner, smaller, faster)
- `yahma/alpaca-cleaned` — quality-filtered Alpaca
- `OpenAssistant/oasst1` — multi-turn conversations
- `HuggingFaceH4/ultrachat_200k` — 200k high-quality chat (much larger)

## Output

```python
from transformers import AutoModelForCausalLM, AutoTokenizer
import torch

model = AutoModelForCausalLM.from_pretrained("microsoft/Phi-3.5-mini-instruct", torch_dtype=torch.float16)
tokenizer = AutoTokenizer.from_pretrained("microsoft/Phi-3.5-mini-instruct")

sd = torch.load("result.pt", map_location="cpu")
model.load_state_dict(sd, strict=False)

prompt = "### Instruction:\nWrite a haiku about programming.\n\n### Response:\n"
inputs = tokenizer(prompt, return_tensors="pt").to(model.device)
out = model.generate(**inputs, max_new_tokens=100)
print(tokenizer.decode(out[0]))
```

## Why Phi-3.5-mini specifically

We surveyed 3 candidates for "small LLM for FL fine-tuning":
- **`microsoft/Phi-3.5-mini-instruct`** ← chosen: 8 benchmark scores published with exact numbers
- `meta-llama/Llama-3.2-3B-Instruct` — also has full numeric table (MMLU 63.4, GSM8K 77.7), strong alternative
- `Qwen/Qwen2.5-3B-Instruct` — defers all numbers to external blog (no card-only metrics)

Phi-3.5-mini's card is the most reproducibly documented.

## Original training recipe (verbatim from Microsoft's `sample_finetune.py`)

Source: https://huggingface.co/microsoft/Phi-3.5-mini-instruct/resolve/main/sample_finetune.py

| Param | Value | Source |
|---|---|---|
| Optimizer | adamw_torch (HF default) | script |
| Learning rate | **5e-6** | script |
| LR schedule | **cosine** | script |
| Warmup ratio | **0.2** (= 20% of total steps) | script |
| Batch size | **4** per-device × grad_accum 1 | script |
| Epochs | **1** | script |
| Sequence length | **2048** | script |
| Weight decay | 0.0 (HF default) | inferred |
| Grad clip | 1.0 (HF default) | inferred |
| Mixed precision | **bf16=True**, gradient_checkpointing=True | script |
| LoRA | **r=16, alpha=32, dropout=0.05**, bias="none", task_type="CAUSAL_LM", target_modules="all-linear" | script |
| Loss | causal LM cross-entropy (TRL SFTTrainer) | script |
| Default dataset | `HuggingFaceH4/ultrachat_200k` (script default; we swap to Alpaca for FL demo) | script |
| Base model context | trained on 3.4T tokens, 512×H100-80G, 10 days; SFT + DPO + PPO | model card |
| Final published metric | MMLU 69, GSM8K 86.2, HumanEval 62.8 | model card |

**FL config matches**: `learning_rate: 5e-6`, `batch_size: 4`, `local_epochs: 1`, 5 rounds → effective 5 epochs of accumulation. LoRA `r=16`, `alpha=32`.

## Caveats

- This is the **vanilla LLM FL setup**. For 7B+ models or faster training, use `job_agent` (Unsloth-based).
- Phi-3.5-mini uses a Phi-specific tokenizer — instruction template isn't quite Alpaca-standard, but the simple `### Instruction: / ### Response:` formatting still trains effectively.
- LR clamp at 2e-4 enforced in `make_fl_adapter` — if you bump it, gradients explode (we observed this with Mistral-7B previously). 5e-6 is far below this clamp so it's safe.
